# 网易大神外卖某会员中心抢券程序 (增强版)

外卖某会员中心自动抢券程序，针对 0 点瞬时秒光场景进行了全方位的高精度狙击与并发压制增强。

---

## 🌟 增强功能特性

1. **精准对齐标准北京时间（消除本地系统时钟偏差）**：
   - 启动时自动从电商/国家授时权威时间源（苏宁、淘宝）请求毫秒时间戳，并测算单向 RTT 延迟，精准校准出与真实**北京时间 (UTC+8)** 的毫秒级偏移量。
   - 彻底摆脱本地电脑时钟慢/快几百毫秒导致的抢券落后或时区换算错误。

2. **提前量补偿（抗网络延迟）**：
   - 默认内置 `80ms` 网络握手提前量，在 `23:59:59.920` 准点打出首发数据包，确保请求在 `00:00:00.000` 到达网易服务器。

3. **四波高密度火力压制（防秒光 & 防补货延迟）**：
   - **Wave 1（准点到达）**：`23:59:59.920` 发射
   - **Wave 2（零点追击）**：`00:00:00.000` 发射
   - **Wave 3（紧随追发）**：`00:00:00.100` 发射
   - **Wave 4（延迟补刀）**：`00:00:00.270` 发射

4. **临门 30 秒自动保活刷新**：
   - 倒计时剩 3 分钟与 30 秒时自动重新校准时间并换取最新鲜的会话 Token。

5. **开箱即用双击脚本**：
   - 提供 Windows 原生 `一键运行.bat` / `run.bat`，拥有独立菜单与常驻保护，彻底解决命令提示符闪退问题。

## 🚀 使用方法

### 1. 前置条件
- 提前在网易大神 App-领券页面-任意点击领券并绑定手机号。
- 安装 Node.js (推荐 v18+ 或 v20+)。
- 在项目根目录下安装依赖：
  ```bash
  npm install
  ```

### 2. 配置账号 Cookie
- 进入 [网易大神会员中心](https://vip.ds.163.com/partner-perks)，使用手机号登录。
- 按键盘 `F12` 打开开发者工具，在 **Application** -> **Cookies** 中提取名为 `NTES_YD_PASSPORT` 的值。
- 将 `passport.example.jsonc` 重命名为 `passport.jsonc`（或新建 `passport.jsonc`），填入数组中：
  ```jsonc
  // passport.jsonc
  [
    "你的NTES_YD_PASSPORT值"
  ]
  ```

### 3. 运行程序
#### Windows 用户（推荐）：
直接双击运行 **`一键运行.bat`** 或 **`run.bat`**，按菜单选择：
- **[1] 刷新登录凭据**：生成 `auth.json`
- **[2] 查询可抢优惠券**：查看当前在架券列表与 ID
- **[3] 立即抢券**：全速并发抢券
- **[4] 定时 00:00:00 狙击抢券**：启动标准北京时间校准并自动倒计时

#### 命令行运行：
```bash
# 刷新凭据
npx tsx run.ts auth

# 查看在架优惠券
npx tsx run.ts list

# 立即抢券
npx tsx run.ts grant

# 启动 00:00:00 北京时间极速狙击
npx tsx run.ts midnight
```
